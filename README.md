# Железяка

Приложение для тренера и подопечных: программа тренировок по шагам, подходы и веса, прогресс, замеры тела.
Все данные хранятся в Google Таблицах тренера. Ничего не нужно покупать или ставить из магазина приложений.

**Открыть приложение: https://kokakolyanv-netizen.github.io/zhelezyaka/**

## Я подопечный

Тренер присылает ссылку с кодом. Откройте её, приложение войдёт само. Чтобы поставить его на телефон:

- **iPhone**: Safari → «Поделиться» → «На экран „Домой“».
- **Android**: Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

## Я тренер: подключаю свои Google Таблицы

Около 10 минут, нужен только Google-аккаунт. Ваши подопечные и программы будут в ваших таблицах;
владелец этого репозитория их не видит.

1. **Скопируйте таблицу-шаблон**: https://docs.google.com/spreadsheets/d/1rMqlmsDhVJ7Ffqv0kfoStyeiksjFtN1ySWhtNnSMyyU/copy → «Создать копию».
2. **Настройте копию.** Откройте её и подождите 5–10 секунд. Справа от «Справка» появится меню
   **«Железяка»**. Выберите **«Железяка → Настроить»**.
   - Google попросит доступ. Выберите свой аккаунт. Если появится «Приложение не проверено» — это ваш собственный
     скрипт в вашей копии: «Дополнительные настройки» → «Перейти на страницу … (небезопасно)» → «Разрешить».
   - После разрешения снова нажмите «Железяка → Настроить». Появятся листы, а на листе **«Настройки»** —
     ваш **код тренера**.
3. **Опубликуйте сервер.** «Расширения → Apps Script» → справа вверху **«Начать развёртывание → Новое развёртывание»**
   → шестерёнка «Выберите тип» → **«Веб-приложение»**. «Запуск от имени»: **Я**. «Кто имеет доступ»: **Все**.
   → «Развернуть» → скопируйте **URL веб-приложения** (заканчивается на `/exec`).
4. **Войдите.** Откройте https://kokakolyanv-netizen.github.io/zhelezyaka/, вставьте адрес сервера в «Адрес сервера» и введите код тренера.
5. **Пригласите подопечных.** «Подопечные» → имя → «Добавить». Для каждого создаётся своя таблица
   с кодом входа. В карточке подопечного кнопка **«Пригласить»** отправляет ему ссылку, которая сразу
   подключает приложение к вашему серверу.

Код тренера работает как пароль ко всем подопечным: никому его не отправляйте. Поменять код можно
на листе «Настройки».

### Уведомление «осталась неделя программы»

Скрипт пишет тренеру, когда подопечный начинает последнюю неделю программы. Проверка идёт после каждой
тренировки и раз в день в 9:00.

- **Email**: адрес на листе «Настройки» (подставляется ваш).
- **Telegram** (по желанию): создайте бота у @BotFather и впишите токен в «Telegram: токен бота». Напишите боту
  любое сообщение, узнайте свой chat id (например, у @userinfobot) и впишите его в «Telegram: chat id».

### Как работает тренер

- **Программа**: карточка подопечного → «Следующая». С нуля, из шаблона или копией текущей. В конструкторе есть
  тренировки, блоки и упражнения из библиотеки. Галочки → «Суперсет» или «Чередование». Подходы, повторы, вес,
  RPE и отдых задаются по неделям, прогрессия ставится одной кнопкой. «Сохранить в таблицу» пишет программу
  отдельным листом в таблицу подопечного.
- **Шаблоны**: в конструкторе «Сохранить как шаблон», на вкладке «Шаблоны» → «Назначить» любому подопечному.
- **Библиотека**: «Новое» → название, мышцы, ссылка на видео, техника. Файл `.mp4` по прямой ссылке играет
  прямо в приложении.
- Всё можно править и прямо в таблицах. В ячейках недель пишите как обычно: `5×6 90кг @7`, `3×10-12`,
  `3×макс`, `40 с`.

### Если что-то пошло не так

- **Нет меню «Железяка»**: обновите страницу таблицы и подождите 10 секунд.
- **«Неверный код входа»**: код тренера — на листе «Настройки», коды подопечных — на листе «Подопечные».
- **«Нет связи с сервером»**: адрес сервера должен заканчиваться на `/exec`, доступ при развёртывании — «Все».
- **Обновили скрипт**: «Начать развёртывание → Управление развёртываниями → ✎ → Версия: новая версия».
  Адрес сервера при этом не меняется.

## Что в репозитории

Сайт приложения (PWA, без сборки) и `backend/Code.gs` — код сервера на Google Apps Script, тот же, что уже
лежит в таблице-шаблоне. Его можно вставить вручную в «Расширения → Apps Script» любой пустой таблицы,
а затем запустить функцию `setup`.
